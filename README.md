# tools.techlit.typing

A single-purpose typing practice game for young students: type a configured word or phrase over and over, correctly, as many times as possible.

**Generative AI disclosure**: I wrote all the functional code and used Claude for help with the visual design.

## Local development

```sh
npm install
npm run dev        # start Vite dev server
npm run build       # type-check (vue-tsc) + production build
npm run preview     # preview the production build locally
```
